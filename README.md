# Koemi (声 × 見る)

Customer feedback intelligence for e-commerce teams: turn review text and order data into evidence-backed issue themes a product manager can investigate.

**Status:** Phase 1 — profiling the Olist dataset. Nothing is built yet.

Built on the [Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (historical data, 2016–2018). See `data/README.md` for how to get it.

See `KOEMI_PROJECT.md` for goals, scope, and the build plan.
