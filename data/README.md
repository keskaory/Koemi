# Data

Raw files are not committed. To reproduce:

1. Download the Olist Brazilian E-Commerce Public Dataset from Kaggle:
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Unzip the CSVs into `data/raw/` (so files look like `data/raw/olist_orders_dataset.csv`).

**License:** check the license on the Kaggle page before publishing derived data or a public demo, and attribute Olist.
